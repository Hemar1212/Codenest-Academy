What is full stack development?

In this video, I explain what full stack development is and give a detailed overview of the technologies used to build full stack web applications. Full stack web development means building the front-end, back-end and database parts of a web application. A full stack developer handles everything from designing the user interface to managing the server-side logic and the database.

I begin with the key technologies and programming languages, including HTML, CSS, JavaScript, Node.js, and front-end frameworks such as React and Angular. Then I move on to server-side technologies like Python, Java and Node.js, and to databases like MySQL and MongoDB, and AWS.

Full stack has 3 parts

  • Front-end
  • Back-end
  • Database
